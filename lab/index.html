    SEO lab: pages broken on purpose

    Each page below triggers a different Search Console status. Verify the site, submit the sitemap, wait, then find each one in the reports.

    How to practise

    1. Add https://anasgenaiva.github.io/ as a URL-prefix property in Google Search Console and verify it.
    2. Submit sitemap.xml under Sitemaps. It is a sitemap index that points to three child sitemaps.
    3. Run URL Inspection on a few lab URLs: “Test live URL”, then “View tested page”.
    4. Wait one to four weeks. Open Indexing, Pages and match each reason to the list below.
    5. Fix one fault, push the change, and click “Validate fix”.

    The test pages

    • Page with a noindex tagExcluded

      Expect: Page indexing: Excluded by ‘noindex’ tag

      Has a robots meta noindex tag but is listed in the sitemap, so Google sees a submitted page it may not index.

    • Page blocked by robots.txtError

      Expect: Page indexing: Blocked by robots.txt (or Indexed, though blocked by robots.txt)

      robots.txt disallows this path while the sitemap submits it.

    • Page with a broken internal linkError

      Expect: Page indexing: Not found (404) for /lab/this-page-does-not-exist/

      Links to a URL with no file. GitHub Pages answers with the custom 404 page and a real 404 status.

    • Redirected pageExcluded

      Expect: Page indexing: Page with redirect

      An instant meta refresh sends visitors to /lab/new-address/. GitHub Pages cannot send a server 301; Google treats an instant meta refresh as a permanent redirect.

    • Redirect chainExcluded

      Expect: Page indexing: Page with redirect (two hops)

      Two meta-refresh hops in a row. Crawlers like Screaming Frog flag this as a redirect chain.

    • Duplicate page AExcluded

      Expect: Page indexing: Duplicate without user-selected canonical (on A or B)

      Same text as /lab/duplicate-b/, and neither page declares a canonical.

    • Alternate with canonicalExcluded

      Expect: Page indexing: Alternate page with proper canonical tag

      Its canonical tag points to /lab/canonical-target/, which holds the same text.

    • Canonical pointing to an unrelated pageExcluded

      Expect: URL Inspection: user-declared canonical differs from Google-selected canonical

      Declares the home page as canonical though its content is unrelated, so Google may ignore the hint.

    • Soft 404Error

      Expect: Page indexing: Soft 404

      Says the item was not found but returns status 200 with almost no content.

    • Thin pageExcluded

      Expect: Page indexing: Crawled, currently not indexed (likely)

      A real but nearly empty page. Google often crawls such pages and declines to index them.

    • Orphan pageExcluded

      Expect: Page indexing: Discovered, currently not indexed (likely)

      No page links here; only the sitemap lists it. Screaming Frog finds it only in sitemap crawl mode.

    • Page missing from the sitemapExcluded

      Expect: URL Inspection: discovered via links, no referring sitemap

      Linked from the lab but deliberately left out of the sitemaps.

    • Recipe with invalid structured dataError

      Expect: Enhancements, Recipes: invalid item (missing image)

      Its Recipe JSON-LD leaves out the required image property.

    • Content added by JavaScriptValid, worth inspecting

      Expect: URL Inspection: the text appears only in the rendered HTML

      The main paragraph is written by a script, so raw and rendered HTML differ.

    • Page without a titleError

      Expect: Crawlers flag a missing title and description; Google writes its own title link

      Has no title element and no meta description.

    • Slow, heavy pageExcluded

      Expect: PageSpeed Insights: poor LCP and CLS in the lab test

      Loads an oversized image without dimensions and shifts the layout after load.

    • Sitemap with errorsError

      Expect: Sitemaps: Has errors (submit it by hand)

      A sitemap with a bad date and a URL on another host.

    Also on this site to practise with

    • A sitemap index with child sitemaps and image entries: sitemap.xml.
    • Paginated lists with rel prev/next: /foods/page/2/.
    • A noindex internal search page: /search/.
    • Structured data: Recipe, Article, BreadcrumbList, ItemList, CollectionPage, WebSite with SearchAction, Organization.
    • A real 404: missing URL.
