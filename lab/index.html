SEO lab

Pages broken on purpose

Each page below triggers a different Search Console status. Verify the site, submit the sitemap, wait, then find each one in the reports.

How to practise

  1. Add https://anasgenaiva.github.io/ as a URL-prefix property in Google Search Console and verify it.
  2. Submit https://anasgenaiva.github.io/sitemap.xml under Sitemaps.
  3. Run URL Inspection on a few lab URLs. Use “Test live URL”, then “View tested page” to compare raw and rendered HTML.
  4. Wait one to four weeks. Open Indexing, Pages and match each reason to the list below.
  5. Fix one fault (for example, remove the noindex tag), push the change, and click “Validate fix”.

Lines show the expected result: solid is valid, dashed is excluded, dotted is an error. Google decides the final status, and timing varies.

The test pages

  • Lab: page with a noindex tag

    Excluded

    Expect: Page indexing: Excluded by ‘noindex’ tag

    Has <meta name="robots" content="noindex"> and is listed in the sitemap, so Google sees a submitted page it may not index.

  • Lab: page blocked by robots.txt

    Error

    Expect: Page indexing: Blocked by robots.txt (or Indexed, though blocked by robots.txt)

    robots.txt disallows this path while the sitemap submits it.

  • Lab: page with a broken internal link

    Error

    Expect: Page indexing: Not found (404) for /lab/this-page-does-not-exist/

    Links to a URL with no file. GitHub Pages answers with the custom 404 page and a real 404 status.

  • Lab: redirected page

    Excluded

    Expect: Page indexing: Page with redirect

    An instant meta refresh sends visitors to /lab/new-address/. GitHub Pages cannot send a server 301, and Google treats an instant meta refresh as a permanent redirect.

  • Lab: redirect chain

    Excluded

    Expect: Page indexing: Page with redirect (two hops: chain-start, chain-middle, new-address)

    Two meta-refresh hops in a row. Crawlers like Screaming Frog flag this as a redirect chain.

  • Lab: duplicate page A

    Excluded

    Expect: Page indexing: Duplicate without user-selected canonical (on A or B)

    Same text as /lab/duplicate-b/ and neither page declares a canonical.

  • Lab: alternate with canonical

    Excluded

    Expect: Page indexing: Alternate page with proper canonical tag

    Its canonical tag points to /lab/canonical-target/, which holds the same text.

  • Lab: canonical pointing to an unrelated page

    Excluded

    Expect: URL Inspection: user-declared canonical differs from Google-selected canonical (often)

    Declares the home page as canonical though its content is unrelated, so Google may ignore the hint.

  • Lab: soft 404

    Error

    Expect: Page indexing: Soft 404

    Says the item was not found but returns status 200 with almost no content.

  • Lab: thin page

    Excluded

    Expect: Page indexing: Crawled, currently not indexed (likely)

    A real but nearly empty page. Google often crawls such pages and declines to index them.

  • Lab: orphan page

    Excluded

    Expect: Page indexing: Discovered, currently not indexed (likely), found only through the sitemap

    No page links here; only the sitemap lists it. Screaming Frog finds it only in sitemap crawl mode.

  • Lab: page missing from the sitemap

    Excluded

    Expect: URL Inspection: discovered via links, “Sitemaps: N/A”

    Linked from the lab but deliberately left out of sitemap.xml.

  • Lab: recipe with invalid structured data

    Error

    Expect: Enhancements, Recipes: invalid item (missing field “image”); Rich Results Test errors

    Its Recipe JSON-LD leaves out the required image property.

  • Lab: content added by JavaScript

    Valid, worth inspecting

    Expect: URL Inspection, View crawled page: the text appears only in the rendered HTML

    The main paragraph is written into the page by a script, so the raw HTML and the rendered HTML differ.

  • Lab: page without a title

    Error

    Expect: Crawlers flag a missing title and description; Google writes its own title link

    Has no <title> and no meta description.

  • Lab: sitemap with errors

    Error

    Expect: Sitemaps: Has errors (submit it by hand)

    A second sitemap with a bad date and a URL on another host. Submit it in Search Console to see the errors.

Also try

  • Request a missing URL and confirm the 404 status in your browser's network panel.
  • Run the Rich Results Test on a recipe page, then on the broken recipe page.
  • Crawl the whole site with Screaming Frog (free up to 500 URLs) and compare its findings with this list.
  • When you are done practising, remove the lab pages or add noindex to them, then let Google recrawl.
