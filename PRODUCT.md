# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain static HTML and CSS, generated by a zero-dependency Node build script (`build.mjs`), tested with `node --test`. Hosted free on GitHub Pages at `https://anasgenaiva.github.io/` (user site, root-level, so Search Console Crawl Stats work). Chosen by the owner.

## Users

- Primary: the owner and a marketer friend practising Google SEO and Google Search Console end to end on a site they fully control, without buying a domain.
- Secondary: real visitors who land from Google looking for plain facts about common foods (protein, fibre, calories per 100 g) and simple recipes.

## Product Purpose

A small, honest nutrition reference ("Plate Notes") whose pages are good enough for Google to index, plus a clearly separated lab of pages broken on purpose, so every Search Console report has something real to show: indexing states, sitemaps, URL Inspection, rich results (Recipe, Article, Breadcrumb), Performance queries, Crawl Stats, and GA4 linking.

Success: the site is indexed, each planted fault appears under its expected Search Console reason, and the marketer can explain and fix each one.

## Positioning

Every number on a food page comes from USDA FoodData Central with the record ID shown, and the lab documents, page by page, which Search Console status each fault should produce. No other nutrition site doubles as an annotated Search Console practice lab.

## Operating Context

- Search Console (URL-prefix property), GA4, Bing Webmaster Tools, Rich Results Test, PageSpeed Insights, Screaming Frog free.
- GitHub Pages limits: no custom HTTP headers or server redirects; redirects are meta refresh; `404.html` returns a real 404.

## Capabilities and Constraints

- Static pages only; one small client-side tool (protein-per-calorie comparison).
- Not medical advice; general information with a visible disclaimer.
- Non-commercial (GitHub Pages terms): no ads, no affiliate links, no shop.
- Must not pretend to be a real business, clinic, dietitian or brand; no LocalBusiness schema.
- FAQ rich results were retired by Google in 2026: do not add FAQPage markup.
- Undecided: GA4 measurement ID and Search Console verification token (the owner supplies both after setup).

## Brand Commitments

None beyond the name "Plate Notes", chosen during this build.

## Evidence on Hand

- USDA FoodData Central records (public domain), fetched at build time and stored in `data/foods.json` with FDC IDs.
- No testimonials, reviews, ratings, authors' credentials or traffic claims exist; never fabricate them.

## Product Principles

1. Every fact is sourced; numbers show their source record.
2. The lab is honest: each broken page says it is broken on purpose and what it demonstrates.
3. Real pages stay clean so planted faults are the only faults.
4. Pages are fast and readable on a phone.
5. Nothing deceptive: no fake authors, reviews or businesses.

## Accessibility & Inclusion

WCAG 2.1 AA: contrast, keyboard access, alt text, semantic headings, reduced motion respected.
